## Featured project (short paragraph)

**Groundline** is my open-source (MIT) template for **durable team knowledge in git**: PR-reviewed Markdown, hybrid retrieval with mandatory rerank, local HTTP API, and optional **MCP** tools for IDE coding assistants. It includes CI validation, golden-query retrieval regression, merge automation for doc lifecycle, MkDocs stakeholder site, and Cursor agent skills for retrieve-first workflows.
